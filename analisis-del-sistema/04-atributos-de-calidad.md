# 04. Atributos de calidad

## Rendimiento

El catálogo y la consulta de disponibilidad deben responder en menos de 200 ms bajo condiciones normales.

## Escalabilidad

La arquitectura debe permitir crecimiento horizontal para soportar más de 10 000 usuarios concurrentes.

## Disponibilidad

El sistema debe estar diseñado para alcanzar una disponibilidad objetivo de 99.9%.

## Seguridad

Las comunicaciones deben utilizar HTTPS/TLS. El acceso debe controlarse mediante autenticación y roles.

## Consistencia

Las operaciones de reservas, ventas e inventario deben mantener la consistencia de los datos.

## Auditabilidad

Las acciones críticas de administración y caja deben quedar registradas para su trazabilidad.

## Mantenibilidad

El sistema debe organizarse mediante módulos y capas para facilitar su mantenimiento y evolución.

## Usabilidad

La aplicación web debe ser responsive para permitir su uso desde computadoras, tablets y otros dispositivos.
