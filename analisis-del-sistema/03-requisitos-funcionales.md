# 03. Requisitos funcionales

| Código | Requisito                                                                                                 |
| ------ | --------------------------------------------------------------------------------------------------------- |
| RF01   | El sistema debe permitir registrar y autenticar usuarios.                                                 |
| RF02   | El sistema debe gestionar roles y permisos.                                                               |
| RF03   | El sistema debe permitir gestionar múltiples sedes.                                                       |
| RF04   | El sistema debe permitir registrar y gestionar servicios.                                                 |
| RF05   | El sistema debe permitir consultar disponibilidad de estilistas y horarios.                               |
| RF06   | El sistema debe permitir reservar citas.                                                                  |
| RF07   | El sistema debe bloquear temporalmente una reserva durante 5 minutos para evitar conflictos concurrentes. |
| RF08   | El sistema debe gestionar los estados de las citas.                                                       |
| RF09   | El sistema debe registrar ventas de servicios y productos.                                                |
| RF10   | El sistema debe permitir diferentes métodos de pago.                                                      |
| RF11   | El sistema debe emitir tickets térmicos.                                                                  |
| RF12   | El sistema debe controlar el inventario por sede.                                                         |
| RF13   | El sistema debe registrar ajustes de inventario indicando motivo y responsable.                           |
| RF14   | El sistema debe gestionar asistencia, turnos y descansos del personal.                                    |
| RF15   | El sistema debe calcular las comisiones correspondientes a los servicios completados.                     |
| RF16   | El sistema debe generar reportes de ingresos, atenciones y stock.                                         |
| RF17   | El sistema debe registrar acciones críticas mediante auditoría.                                           |
